# `CafeteriaApplication`

**Paquete:** `g5.backend.cafeteria`  
**Estereotipo / Anotaciones:** `@SpringBootApplication`

> Punto de entrada principal para la aplicación Spring Boot del backend de Cafetería. Configura el arranque automático, el escaneo de componentes y la inicialización del contexto.

## Métodos

### `main(String[] args)`
```java
public static void main(String[] args)
```

Método principal que inicia la ejecución de la aplicación Spring Boot.

* **Parámetros:**
  * `args`: Argumentos pasados por línea de comandos durante la ejecución.
