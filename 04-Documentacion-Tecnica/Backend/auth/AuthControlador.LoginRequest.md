# `AuthControlador.LoginRequest` *(record)*

**Paquete:** `g5.backend.cafeteria.auth`  
**Clase contenedora:** `AuthControlador`

> Estructura de datos que encapsula las credenciales de inicio de sesión enviadas por el cliente.

## Componentes
| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `correo` | `String` | Correo electrónico registrado del usuario. |
| `contrasena` | `String` | Contraseña en texto plano para validación. |
