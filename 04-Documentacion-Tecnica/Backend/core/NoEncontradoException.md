# `NoEncontradoException`

**Paquete:** `g5.backend.cafeteria.core`  
**Estereotipo / Anotaciones:** Excepción de tiempo de ejecución (`RuntimeException`)

> Excepción lanzada cuando una entidad o recurso solicitado no existe en la base de datos o en el sistema. Es capturada por el manejador global para responder con un código de estado HTTP 404 (NOT_FOUND).

## Dependencias (Constructor)
- `String mensaje`
